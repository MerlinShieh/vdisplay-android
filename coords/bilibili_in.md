## ⚠️ 采集方式的坑（务必记住）

**B站国际版是 Jetpack Compose 界面，`uiautomator dump` 会失败**：
```
ERROR: could not get idle state.
```
原因是首页视频 feed 持续刷新动画，永远不进入 idle。

**改用无障碍服务即可**：
```sh
android-a11y-cli ui dump > /tmp/x.json
```
返回 JSON，字段 `text` / `contentDesc` / `center.{x,y}` / `clickable`。
B站很多元素只有 `contentDesc` 没有 `text`，解析时两者都要看。

## 安全约束
- **禁点「一键已读」(1052,220)** —— 会清空用户未读状态
- **禁点「发布」(1117,1311)** —— 会发布动态
- **禁点视频页的发弹幕 (969,934)、评论输入框 (581,2635)、表情 (1202,2635)** —— 会发出内容
- **点赞/投币/收藏/关注** 都会改状态，非用户明确要求不要点
- 浏览时只允许：切标签、切底部导航、滚动、打开列表项、返回
