- **注意**：知乎在虚拟屏上会自动跳主屏，控件树只能在**主屏前台**采集
- **重要：坐标表在虚拟屏上同样有效**。虚拟屏与主屏同参数（1280×2772@520dpi，运行时读取），控件坐标 1:1 通用。只有「采集」阶段需要在主屏跑 `uiautomator dump`，之后「使用」阶段直接在虚拟屏注入坐标即可，无需切前台。

## 推荐流

- 卡片为无 id 的 ViewGroup，**只能靠文字内容定位**
- 正文节点 y 与卡片顶部差约 80
- 建议：先 `dump` 取当前 `text`，再按文本匹配点击，不要写死坐标

### 踩坑记录：input 参数顺序

`input` 的语法是 **`input [<source>] [-d DISPLAY_ID] <command> [args]`**，`-d` 必须在子命令之前。

```sh
input -d 231 swipe 640 1900 640 1300 500    # ✅ 正确
input swipe 640 1900 640 1300 500 -d 231    # ❌ 静默失败，不报错
```

**症状**：滑动/点击看似执行了，但画面 md5 完全不变 —— 因为事件被注入到了默认屏（主屏）。
**排查**：对比操作前后的截图 md5；若不变，先怀疑注入参数。

## 安全约束
- **禁点「全部已读」`Block:all_read`** —— 会清空用户未读状态
- 采集/浏览时只允许：切标签、滚动、打开列表项、返回
- 不点「+」发布按钮 (640, 2612)
